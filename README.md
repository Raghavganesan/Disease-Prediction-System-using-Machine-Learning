<h2>Disease Prediction System using Machine Learning</h2>

 <p>
  <img width="675" height="386" alt="image" src="https://github.com/user-attachments/assets/cb42429c-dc5a-4ba4-94ee-bb475917ece4" />

  A medical diagnosis system developed using <strong>Machine Learning algorithms</strong> 
    (Naïve Bayes, SVM, Random Forest, CNN) to predict <strong>41+ diseases</strong> 
    from <strong>132 symptoms, age, and gender</strong>. 
    Designed to act as a virtual doctor for early diagnosis and improved healthcare access.
  </p>

   <ul>
    <li>Dataset: 41 diseases, 132 symptoms</li>
    <li>Algorithms: Naïve Bayes, SVM, Random Forest</li>
    <li>Highest Accuracy Achieved: 93.5% (Weighted KNN)</li>
  </ul>

   <h3>Objectives</h3>
  <ul>
    <li>Develop predictive ML models for disease detection based on symptoms.</li>
    <li>Evaluate models to determine the most accurate predictions.</li>
    <li>Create a user interface for symptom input and disease output.</li>
    <li>Ensure scalability for large datasets of symptoms and diseases.</li>
    <li>Make the system interpretable for users to understand predictions.</li>
  </ul>

  <h3>Design</h3>
  <img width="1349" height="634" alt="image" src="https://github.com/user-attachments/assets/3b7bda8b-91ea-43fb-bedd-c45c1fccc8ab" />

  <ol>
    <li><b>Data Handling:</b> Collected diverse datasets, handled missing values, encoded variables, and split into training/testing sets.</li>
    <li><b>Model Selection & Training:</b> Used Naïve Bayes, SVM, Random Forest with hyperparameter tuning for better accuracy.</li>
    <li><b>Evaluation & Validation:</b> Measured performance with accuracy, precision, recall; tested with real-world cases.</li>
    <li><b>Prediction Function & UI:</b> Developed modular function for input/output and user-friendly interface with error handling.</li>
    <li><b>Deployment & Maintenance:</b> Focused on scalability, reliability, and long-term usability with feedback integration.</li>
  </ol>
  
  <h3>Results</h3>
  <img width="1314" height="754" alt="image" src="https://github.com/user-attachments/assets/a6248a13-917f-47c2-a270-9a6681085ea9" />

  <ul>
    <li>Achieved <b>93.5% accuracy</b> with Weighted KNN; most models delivered strong performance.</li>
    <li>Predicted 41+ diseases using symptoms, age, and gender with high accuracy.</li>
    <li>Acts as a <b>virtual doctor</b> for early detection, useful in remote areas and emergencies.</li>
    <li>Reliable through rigorous preprocessing (bias removal, feature encoding, dataset balancing).</li>
    <li>Proved highly effective during situations like <b>COVID-19</b> where doctors/resources are limited.</li>
  </ul>
